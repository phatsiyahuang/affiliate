แปลงลิงก์ Affiliate

วางลิงก์สินค้าหรือโรงแรม ระบบจะดูให้ว่าเป็นของแพลตฟอร์มไหน แล้วแปลงเป็นลิงก์ Affiliate ของคุณ

บันทึกลิงก์นี้ให้:

⚙️ ตั้งค่ารหัส Affiliate ของแต่ละแพลตฟอร์ม
Shopee

ดูได้ที่ Shopee Affiliate → บัญชีของฉัน

Trip.com

ดูได้ที่ Trip.com Affiliate → Tools → Link

Lazada

คัดลอกรูปแบบ Deep Link จากพอร์ทัล Lazada Affiliate แล้วใส่ {url} ตรงตำแหน่งลิงก์สินค้า และ {sub} ตรงรหัสแคมเปญ

TikTok Shop: สร้างลิงก์ได้ในแอปเท่านั้น ให้คัดลอกลิงก์จากแอปมาใส่ในช่องลิงก์ของรายการได้เลย · Facebook / Instagram / Lemon8: เป็นช่องทางโพสต์ ใช้ลิงก์ของ Shopee/Lazada/Trip.com/TikTok Shop ไปแปะ
